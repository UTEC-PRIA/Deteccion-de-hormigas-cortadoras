# Estructura
| Carpeta | Contenido |
|---|---|
| `app/` | Dashboard, plan de vuelo, drones, visor y `static/` |
| `datos/vuelos/f450_gopro/`, `datos/vuelos/dji_mini2se/` | Un vuelo por carpeta: telemetría, visor, miniaturas (`fotos/` y `video/` sólo en la PC) |
| `datos/planes/`, `datos/simulados/`, `datos/ejemplos/` | Planes y datos de prueba |
| `docs/guias/`, `docs/informes/`, `docs/investigacion/` | Documentación |
| `lanzadores/linux/`, `lanzadores/windows/` | Accesos directos (`ejecutar.sh` queda en la raíz) |
| `herramientas/` | Generadores, batería e instaladores |
| `config/` | Credenciales de la GoPro |
| `legado/` | Versión anterior, no usada por el dashboard |
| `tests/` | Pruebas sin hardware |
